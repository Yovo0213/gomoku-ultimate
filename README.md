# 落与砚的五子棋

一个只在本机运行的双人五子棋：落在浏览器里落子，砚从两人正在使用的 Codex 任务上下文中判断自己的下一手，并可以在棋盘旁留下一句简短的话。

## 当前第一版

- 15×15 棋盘、胜负判断、悔棋、换边和棋谱。
- 固定为落与砚对局，不展示通用 AI 模式、难度菜单或竞技倒计时。
- 本地棋力模块只提供候选点；最终落子由绑定的 Codex 任务结合真实聊天上下文选择。
- 常驻检测器会在出现待处理棋局时自动接手；不需要落再复制口令或去另一个窗口叫醒砚。
- 如果当前 Codex 任务仍在回复，检测器会等待任务完整结束后再读取，避免使用半截上下文。
- 每一手都从当前任务最新记录创建一次性、最小权限分支；不会修改真实任务的权限、历史或工作区。
- 分支只能使用内存中的 `read_game` 与 `place_move`，不能访问项目文件、网络、Shell、插件或其他工具。
- Codex 返回的坐标会在服务端和浏览器端分别校验，非法位置不会写入棋局。
- 待处理回合原子保存在 SSD；服务重启、网络重试或迟到请求不会重复落子、串局或让旧棋盘覆盖新棋盘。
- Codex 断开或输出无效时最多自动尝试三次，随后明确停住并把重试按钮交还棋盘，不会切换成本地机器人冒充砚。
- 桌面和手机宽度均可使用。

## 本地运行

需要 Node.js 20+、npm，以及已能在本机使用的 `codex` CLI：

```bash
npm ci
npm run dev
```

打开 `http://127.0.0.1:8082/`。

正式构建与本地服务：

```bash
npm run build
npm start
```

可选环境变量：

- `LUO_GOMOKU_PORT`：正式服务端口，默认 `8082`。

## macOS 后台检测器

安装器会把正式服务与检测器注册为两个仅本机可见的 LaunchAgent，并为棋局分支建立独立的 Codex 配置目录。它只链接现有登录凭据，不读取或复制凭据正文。

```bash
npm run install:macos -- \
  --thread-id <要绑定的 Codex 任务 UUID> \
  --workspace "/Users/joeyzhang/Documents/New project"
```

运行状态保存在项目的 `.runtime/`（已被 Git 忽略）；棋局页面仍是 `http://127.0.0.1:8082/`。普通落子可以完全安静，砚确实想说话时，短句只显示在棋盘界面，不会伪造一条真实聊天历史。
